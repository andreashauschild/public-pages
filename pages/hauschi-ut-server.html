Spiel herunterladen

Option 1: Fertiges ZIP (empfohlen)

Ich habe ein fertiges Paket vorbereitet — einfach herunterladen, entpacken und losspielen. Kein Installer, kein Patchen nötig. Den Download-Link findet ihr in der Beschreibung des TeamSpeak-Channels „Unreal Tournament 99 Server“ (See Info). Nach dem Entpacken startet ihr das Spiel über: System\UnrealTournament.exe

oder

Option 2: Selbst installieren

Falls du es lieber selbst einrichten möchtest:

  1. Lade den Unreal Tournament Installer herunter:
    oldunreal.com → Full Game Installers
  2. Installiere das Spiel ganz normal auf deinem PC.
  3. Lade den OldUnreal Patch v469e für Windows herunter:
    GitHub → UnrealTournamentPatches Releases
    Du brauchst die Datei: OldUnreal-UTPatch469e-Windows-x86.zip
  4. Entpacke das ZIP und kopiere alle Dateien in dein UT-Installationsverzeichnis (z.B. C:\UnrealTournament\). Bestehende Dateien überschreiben!
  5. Starte das Spiel und verbinde dich auf den Server.
Wichtig: Der Server läuft auf Version v469e. Damit du dich verbinden kannst, muss dein Spiel ebenfalls auf v469e gepatcht sein!
